# PORTUGUÊS

Para funcionar, é recomendado a utilização do SQL SERVER 2022 (Utilizado para o projeto).

Necessário rodar primeiro os scripts da pasta "Database > Tables". Logo após, rodar os scripts da pasta "Database > Procedures". A ordem das procedures não irá influenciar, porém a ordem das tabelas, é necessário rodar a "SalesDetails" após as outras duas.

# ENGLISH
To work, it's recommend to use SQL SERVER 2022 (Used in project).

You need to run first the scripts on folder "Database > Tables". After, you will run "Database > Procedures". Just on "Tables", you need to run last "SalesDetails".
